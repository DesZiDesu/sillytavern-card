# Prompts

Store the reusable prompt material for the Honkai Impact 3rd SillyTavern bot here.

Suggested files:

- `system.md` — project-wide behavior and setting rules
- `scenario.md` — starting scenario or campaign premise
- `author-note.md` — reusable Author's Note content
- `style.md` — prose, dialogue, pacing, and formatting requirements
- `guardrails.md` — continuity and characterization constraints

Character-specific prompt text may remain inside each character folder under `../characters/`.
