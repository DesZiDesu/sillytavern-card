# Characters

Store the Honkai Impact 3rd SillyTavern character cards and their editable source data here.

Recommended layout:

```text
characters/
└── character-name/
    ├── card.json
    ├── card.png
    ├── notes.md
    └── assets/
```

Keep one subfolder per bot or character. Do not place the shared portrait library here; use `../assets/galleries/` for gallery access.
