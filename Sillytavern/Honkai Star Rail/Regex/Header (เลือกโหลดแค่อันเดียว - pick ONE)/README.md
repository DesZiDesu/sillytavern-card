# HSR Character Header — install ONE

All three files use:

`[HSRCHAR|slug|Name|element|path|faction]`

Import exactly one:

| File | Design |
|---|---|
| `HSR_Header_A_AstralTicket_Regex.json` | Astral Ticket — ivory HSR menu surface, thin ticket geometry, portrait on the right |
| `HSR_Header_B_WarpNameplate_Regex.json` | Warp Record — dark navy warp-result panel, five-star detail, portrait on the right |
| `HSR_Header_C_Constellation_Regex.json` | Data Bank — pale silver database panel, minimal geometric mark, portrait on the right |

Portraits load from `Sillytavern/Honkai Star Rail/Images/<slug>.jpg`.

Matching dialogue and monologue files use the same A/B/C set names.
