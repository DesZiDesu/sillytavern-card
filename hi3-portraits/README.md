# Honkai Impact 3rd Character Galleries

This folder contains the Honkai Impact 3rd gallery tools and installed collection manifests for `DesZiDesu/sillytavern-card`.

## Entry points

- `gallery.html` — combined searchable character gallery
- `index.html` — battlesuit avatar downloader
- `male.html` — curated male avatar downloader
- `packs/registry.json` — registered source ZIP metadata, file counts, and SHA-256 checksums

## Installed collections

- Battlesuit Avatars: 124 official-source images
- Male Characters — Option A: 26 official-source images

The gallery uses the source URLs recorded in the manifests so it works directly through RawGitHack while retaining exact source attribution. The source-pack registry records the two supplied ZIP archives independently from the rendered remote-source collections.

## SillyTavern card

The description-only Honkai Impact 3rd RPG card is stored at `../Honkai Impact 3rd/characters/honkai-impact-3rd-rpg/card.json`. Its First Message, Personality, and Scenario fields are intentionally blank for later authoring.
