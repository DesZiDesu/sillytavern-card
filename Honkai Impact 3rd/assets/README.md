# Assets

Shared assets used while building the Honkai Impact 3rd SillyTavern bot belong here.

- `galleries/` — entry point to the character portrait galleries
- future character-specific images should normally be stored with the relevant card under `../characters/character-name/assets/`

The existing `hi3-portraits/` directory is the portrait-tool and gallery resource library; it is linked from this workspace rather than treated as the bot project root.
